# tim-14
Platforma za privatne casove - Platforma za privatne časove na kojoj profesori, verifikovani od strane admina, objavljuju oglase za časove (npr. pripremu za prijemni ili određeni predmet) sa cenama i ostalim informacijama, a učenici mogu da pregledaju njihove profile, zakazuju časove i ostavljaju recenzije nakon održanog časa.
